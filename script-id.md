# MyHeritage — Naskah Video Explainer 2D (Bahasa Indonesia)

**Durasi target:** ±2 menit (±300 kata, ±145 kata/menit — diukur dari voice Piper id_ID).
**Gaya:** "money stories drawn on paper" — narator + 2 skit dialog singkat.
**Voice:** Piper `id_ID-news_tts-medium` (satu speaker; karakter dibedakan lewat `length_scale`:
narator 1.0, Dimas 1.05, Ibu 0.95, Rani 1.05).

## Fakta terverifikasi (dipakai di naskah)
- Didirikan 2003 oleh Gilad Japhet; berawal dari program silsilah keluarga yang ia buat
  umur 13 tahun untuk tugas sekolah; ia sempat cuti enam bulan untuk menulis software
  pohon keluarganya sendiri; dibangun dari ruang tamu rumahnya di Israel.
- Situs myheritage.com dibuka 2005; tersedia dalam 42 bahasa.
- Fitur Smart Matches (pencocokan pohon keluarga) diluncurkan 2007.
- Tes DNA diluncurkan 2016 (usap pipi, dibandingkan dengan 2.114 wilayah);
  6,5 juta+ kit terjual sampai Maret 2023.
- 19,9 miliar catatan sejarah.
- Diakuisisi Francisco Partners awal 2021 seharga $600 juta.
- Kantor pusat Or Yehuda, Israel.
- Angka besar selalu disertai perbandingan sehari-hari (lihat naskah).

- Jumlah pengguna terdaftar saat ini (tidak dikutip — angka berubah cepat).
- Harga tes DNA / paket langganan (tidak dikutip — bisa berubah).
